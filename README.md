Amazon Sales Performance Dashboard

Project Overview

An interactive sales analysis dashboard built using Microsoft Excel to explore sales performance, revenue, profit, and order trends.

Tools Used

- Microsoft Excel
- Excel Tables and PivotTables
- PivotCharts
- Slicers
- KPI Cards

Key Performance Indicators

- Total Revenue
- Total Profit
- Total Orders
- Profit Margin
- Average Order Value

Dashboard Features

- Revenue and profit analysis
- Revenue by category
- Revenue by region
- Profit by category
- Order status analysis
- Interactive filters for region, category, status, and product

Files

- "Amazon_Sales_Report_Under_1000_Orders.xlsx" — Excel workbook containing the dashboard and sales data.

Skills Demonstrated

Data cleaning, aggregation, PivotTables, dashboard design, KPI reporting, and interactive data analysis.

Dataset Note

This project uses a sample sales dataset for learning and portfolio demonstration. Results should not be interpreted as actual Amazon company sales figures.
